# ResolveAI

## AI IT Service Desk Autonomous Resolution Agent

ResolveAI is an AI-powered IT service desk agent that analyzes employee IT problems, identifies the issue type, provides troubleshooting steps, and decides whether the issue can be resolved automatically or should be escalated to human IT support.

## Features

- Ticket triage
- Issue classification
- Knowledge-based diagnosis
- Troubleshooting recommendations
- Autonomous resolution
- Human escalation

## Supported Issues

- Wi-Fi / Network problems
- Slow computer / Performance issues
- VPN problems

## Tech Stack

- Python
- Streamlit
